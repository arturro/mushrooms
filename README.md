# Mushrooms

Minimal full‑stack starter: Vite + React/TypeScript frontend, Django + Ninja API backend, PostgreSQL via Docker Compose.

Generated by GPT-5.

## Stack

- Frontend: Vite + React + TypeScript (port 5173)
- Backend: Django 5 + Django Ninja (port 8000)
- DB: PostgreSQL 16 (host port 5433 → container 5432)
- Dev containers: Docker Compose
- Local Python tooling: uv (optional) / Python 3.12

## Quick start (Docker, recommended)

Prerequisite: Docker Desktop

```powershell
# From repo root
docker compose up -d --build

# Open apps
# Frontend: <http://localhost:5173>
# Backend health: <http://localhost:8000/api/health>
# Ninja Organismus list (paginated): <http://localhost:8000/api/organismus/>
# Ninja Article by slug (e.g., about): <http://localhost:8000/api/article/about>
# Postgres: localhost:5433 (db=mushrooms, user=mushrooms, password=postgres)
```

## Local dev (without Docker)

Prerequisites: Node 20+, Python 3.12 (optionally uv)

Frontend

```powershell
cd .\frontend
npm install
npm run dev
# http://localhost:5173
```

Backend (SQLite by default if POSTGRES_* not set)

```powershell
cd .\backend
# Using uv (recommended)
uv run python manage.py makemigrations
uv run python manage.py migrate
uv run python manage.py runserver 0.0.0.0:8000
# http://localhost:8000/api/health
```

Connecting backend to local Postgres (optional)

```powershell
# Set env vars before starting the backend
$env:POSTGRES_DB = "mushrooms"
$env:POSTGRES_USER = "mushrooms"
$env:POSTGRES_PASSWORD = "postgres"
$env:POSTGRES_HOST = "localhost"
$env:POSTGRES_PORT = "5433"
uv run python manage.py migrate
uv run python manage.py runserver 0.0.0.0:8000
```

## Admin and content

- Django admin: <http://localhost:8000/admin/>
- Create a superuser:

```powershell
cd .\backend
uv run python manage.py createsuperuser
```

- Content types:
  - Organismus: name, latin_name, description, image; API at `/api/organismus/` and `/api/organismus/{id}`
  - Article: title, description, content, image, author, auto‑slug; API at `/api/article/{slug}` (e.g., `about`)

## Notes

- Frontend dev server uses hot reload; Docker setup mounts sources and enables polling for reliable file watching.
- Media files (images) are served at `/media/` in DEBUG. For production, use a proper storage backend.
- Compose maps Postgres to host 5433 while services talk to `db:5432` internally.
